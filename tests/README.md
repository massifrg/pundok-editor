# Test fixtures

`testsuite.json` is derived from Pandoc's `testsuite.native` test fixture.
The original fixture is part of the Pandoc test suite:

- [Pandoc test suite](https://github.com/jgm/pandoc/tree/main/test)

This project includes the fixture as a test input for validating the
Pandoc JSON parser and exporter. Credit and acknowledgment go to the
Pandoc authors and contributors.
